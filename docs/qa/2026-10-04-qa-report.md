## 5. 결함이 아닌 확인 결과 · 개선 제안

**보안 — 통과**: 보안 헤더(CSP · X-Frame-Options · nosniff · Referrer-Policy · COOP · Permissions-Policy)가 웹 · API · 404 · 오류 · Swagger · 프록시 모든 경로에 있음. CORS 는 `localhost:3300` 만(다른 출처 · `null` 403). 관리 토큰은 상수 시간 비교 · 없음/빈 값/틀림 401 · 경로 변형도 요청 한도 안. SQL 은 모두 바인딩(매트릭스의 SQL · 와일드카드 문자열은 결과 0건 또는 400). XSS 싱크(`dangerouslySetInnerHTML` 등) 없음, 지도 라벨은 textContent. 상태를 바꾸는 요청은 사용자 정의 머리글(X-Admin-Token) 이 필요하고 쿠키 인증이 없어 CSRF 해당 없음. 실제 키 값: 앱 로그 · 호출 기록(`params_masked`) · 수집 상태 응답 · 웹 번들에서 0건(웹 번들의 카카오 JS 키는 설계상 공개 · 도메인 제한). 취약점: npm audit 0 · pip-audit 0 · Dependabot 0 · CodeQL 0. 런타임: Java 21(~2029) · Spring Boot 4.1(~2027-07) · Node 24(~2028-04) · Python 3.13(~2029-10) · PostgreSQL 16(~2028-11) · Redis 7.4(상용판 기준 2026-11-30 종료 → 2026-10-05 Redis 8 로 올림, ADR-028) · React 18(활발한 지원 종료, ADR-022 의 조건부 유지).

**개선 제안(결함 아님)**
1. **공개 배포 전 필수**(README 체크리스트에 이미 있음): `/ops/collect-status` 의 오류 상세(스택 트레이스 · 마스킹된 호출 파라미터)를 관리 토큰 뒤로, Swagger 끄기, Redis 비밀번호 · maxmemory. → **조치**(2026-10-05, [ADR-028](../adr/028-public-hardening-redis8.md)): 앞의 셋. `maxmemory` 는 예산 · 잠금 키가 밀려날 위험 때문에 남김.
2. **백업 · 복원 절차 없음** — 이번에 `pg_dump -Fc` → `pg_restore` 로 232MB 를 11초에 복원(행 수 일치)했다. 정기 백업 · 복원 명령(`make backup/restore`)과 보관 위치를 문서로 남길 것을 권한다. → **조치**: `make backup` · `make restore-check` · `make restore`([ADR-027](../adr/027-db-backup-restore.md)).
3. Redis 장애 때 요청 한도는 열린 채(통과) 동작한다(설계, 경고 로그). 외부 API 예산은 닫힌 채(호출 안 함)라 비용 위험은 없다.
4. API 를 직접(8300, 127.0.0.1 전용) 부르면 Tomcat 이 거른 요청(인코딩한 `/` · NUL · 8KB 넘는 머리글)은 HTML 400 — 웹 프록시는 QA-06 으로 JSON 으로 바꾼다.
5. `fromStation` 에 좌표와 맞지 않는 역 코드를 넣어도 받아들인다(화면은 만들지 않는 조합). 역 좌표와 1km 안인지 검사하면 조작 입력을 막을 수 있다.
6. 모바일 LCP(Lighthouse 느린 4G 흉내) 3.6~3.9초(`/` · `/road` · `/road/SEL-DJN` · `/rail`) — 성능 점수 80~86. 실제 지도가 그려지는 개발 스택의 `/` 는 지도 타일 이미지가 LCP 요소가 되어 **7.4초 · 성능 69**다. 히어로 지도 타일 · 폰트 · 차트를 늦게 불러 첫 글자를 먼저 그릴 여지가 있다.
7. 같은 선택을 1초 안에 되돌리면(예: 기간 30일 → 90일 → 30일) 같은 주소를 다시 부른다(서버 캐시로 3ms). 화면 쪽 짧은 캐시로 줄일 수 있다.
8. 개발 DB 컨테이너 로그에 **이전 세션의 점검 쿼리가 남긴 UTIC 키 한 줄**이 있었다(제품 결함 아님 — 2026-09-28 수동 확인 쿼리가 실패하며 기록됨). → **조치 끝**: 컨테이너를 다시 만들어(데이터 볼륨 유지) DB · API · 수집기 · 웹 로그의 키 값 0건을 확인했다. 이 재시작에서 QA-10 을 찾았다.

**아키텍처**: 이번 범위에서 새 계층 위반 · 순환 의존은 없다(`ArchitectureTest` 통과).
