## 알려진 한계 (수치로 확인됨)

- **중간역 지연 보간(P-i1)은 지연을 과소 추정하는 경향.** 종착역 정확 비교(EXACT)가 대부분인 방향의 정시율(서울→부산 66.7%, 동대구→부산 68.9%)이 보간(EST)이 대부분인 방향(부산→동대구 97.7%, 서울→천안아산 96.8%)보다 낮다. 지연은 종착역 부근에서 비선형으로 쌓이는데 선형 보간이 이를 반영하지 못하는 것으로 보인다. 화면에 ⚠ 추정과 추정 비율을 표시한다. 개선 후보: 역별 표준 운행시간(최빈값) 기반 계획 시각 추정.
- **자동차 시간은 영업소(TG)→영업소 구간 합**이라 도심 구간이 빠진다. 카카오 미래 운행 정보(도심 포함 경로)와 나란히 보여 준다.
- **도로공사 공개 지연(수 시간)** 때문에 "지금" 도로 값은 몇 시간 전 관측을 M1 로 끌어온 예측이다 (`leadMin` 표시). 자정 직후 전날 마지막 몇 시간 슬롯은 API 가 날짜를 넘겨 버려 받을 수 없다 (결측 사유 `SOURCE_EXPIRED`).
- 기준선·백테스트는 데이터가 쌓여야 의미가 있다. 표본 수를 항상 함께 표시하고, 부족하면 '—' 로 표시한다.
