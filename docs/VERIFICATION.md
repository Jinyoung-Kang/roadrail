## 알려진 한계 (수치로 확인됨)

- ~~중간역 지연 보간(P-i1)은 지연을 과소 추정하는 경향~~ → **해결(29·30번)**: 첫날 관찰(종착 정확 비교 방향의 정시율이 보간 방향보다 낮음)을 TAGO 시간표 비교로 확인했다 — 서울→대전 30일 89.7% → 83.9%. 이제 통계는 실제 계획 시각과 비교한 운행만 쓴다.
- TAGO 시간표가 비어 있는 날의 중간역 운행은 확인 불가로 빠진다(서울→대전 30일 중 347회).
- 기차 환승은 **코레일 여객열차끼리만** 다룬다. 지하철·버스 환승 경로는 공개 데이터로 만들 수 없어(TAGO 는 역별 시각만) 다루지 않는다. 역까지 도보(1km 미만)는 공개 도보 길찾기 API 가 없어 추정한다('도보 추정' 표시).
- 도로 종류는 이름으로 분류하므로 도로명으로 표기된 국도 구간은 일반도로로 집계된다.
- 고속도로 **실측** 추이(평소 대비 정체)는 수집 중인 8개 길에서만 제공한다. 그 밖은 카카오 경로 예측이다.
