# 화면 값의 출처 (2026-09-25 전 메뉴 점검)

원칙: 화면에는 **공식 API 가 준 값**, 그 값으로 **계산한 통계**, **예측**이라고 밝힌 값만 낸다.
모르는 값을 규칙이나 짐작으로 채우지 않는다. 대체할 실제 값이 없으면 지운다. 다만 기능에 꼭 필요하고
영향이 작으며 화면에 '추정'으로 밝히는 두 가지는 남겼다(맨 아래).

## 판단 (출발지 → 도착지)

| 값 | 출처 | 구분 |
|---|---|---|
| 자동차 소요 · 거리 · 경로선 | 카카오모빌리티 미래 운행 정보 (출발 시각 기준) | 예측 (카카오) |
| 평균 속도 | 위 거리 ÷ 소요 | 계산 |
| 고속도로 실측 · 평소 대비 · 예측 | 도로공사 영업소 간 통행시간 합 · 8주 기준선 · M0/M1 | 실측 · 통계 · 예측 |
| 역까지 · 역에서 (1km 이상) | 카카오 실제 운전 경로 — 못 얻은 역은 후보에서 제외 | 실측 경로 (카카오) |
| 열차 구간 출발 · 도착 시각 | 기준일의 코레일 운행계획(시발·종착) · TAGO 역별 계획 시각 | 공식 시간표 |
| 차종 | TAGO 시간표 `traingradename` (없으면 표시 안 함) | 공식 |
| OO발 OO행 | 코레일 운행계획의 시발·종착역 | 공식 |
| 30일 정시율 · 평균 지연 | 운행정보(실제) − 계획 시각(운행계획 · TAGO). 계획 시각을 모르는 운행은 제외 | 통계 |
| 선로 경로선 | OpenStreetMap 선로 · 열차가 선 역 순서대로 역 쌍 최단 선로 | 공개 지도 데이터 |
| 날씨 · 대기질 | 기상청 단기예보 · 에어코리아 | 예보 · 실측 |
| 돌발 안내 · 위치 | 도로공사 문자 안내 (좌표는 응답에 있을 때만) | 공식 |

## 도로 분석

| 값 | 출처 | 구분 |
|---|---|---|
| 추천 · 고속도로 회피 경로, 출발 시각별 소요 | 카카오 미래 운행 정보 | 예측 (카카오) |
| 도로 구성 | 이름에 '고속도로'가 있는 구간 / 그 외 도로 | 공식 이름 그대로 |
| 도로별 소통 · 느린 구간 | 카카오 `traffic_state` | 공식 |
| ~~국도 · 도시고속도로 비율~~ | 이름 패턴 · 기억한 도로 목록으로 분류 → **삭제** (카카오 도로명에는 '국도' 표기가 없음) | — |
| ~~통행료~~ | 카카오 `fare.toll` 이 서울→대전에도 0원 → **표시 안 함** | — |

## 철도 분석

| 값 | 출처 | 구분 |
|---|---|---|
| 정시율 · 지연 분포 · 요일 · 시간대 · 열차 랭킹 | 운행정보 − 계획 시각(EXACT · TT) | 통계 |
| ~~중간역 지연 보간 (P-i1)~~ | 시발·종착 지연을 경과시간 비율로 선형 보간 → **통계에서 삭제**, TAGO 시간표(TT)로 대체. 시간표가 없는 날은 '확인 불가' | — |
| ~~열차 종류 T-v1~~ | 열차 번호 범위로 짐작 → **삭제** (검증해 보니 01501 은 무궁화호가 아니라 ITX-마음). TAGO 차종으로 대체 | — |
| 차종 · OO발 OO행 | TAGO 시간표 · 코레일 운행계획 | 공식 |

## 예측 성능 · 수집 상태

모델 예측값(M0 · M1 · 지속)과 백테스트 오차, 수집 작업의 실제 실행 기록 · 호출 수 · 완전성. 추정 값 없음.

## 남겨 둔 추정 두 가지

| 값 | 왜 실제 값이 없나 | 왜 남기나 | 화면 표시 |
|---|---|---|---|
| 역까지 도보 시간 (1km 미만) | 공개 도보 길찾기 API 없음 (카카오 없음 · TMAP 보행자 API 는 별도 키) | 짧은 거리라 판단에 주는 영향이 작고, 없으면 역 옆 출발지의 기차 비교가 불가능 | '도보 추정' |
| 앞으로의 시간표 = 최근 같은 요일의 실제 시간표 | 코레일 API · TAGO 모두 미래 시간표 없음 (TAGO 미래 날짜 0건 실측) | 기차 비교의 전제. 쓰는 시각 자체는 그날의 실제 시간표 | '시간표 기준 09-18 (같은 요일 최근 운행일)' |

환승 경로 탐색(CSA)의 내부 계산은 시간표가 없는 중간역에 보간 시각을 쓰지만, 화면에 내는 구간 시각은 실제 시간표로
바꾸고 그 시각으로 승차 · 환승이 되는지 다시 확인한다. 시간표를 받지 못한 구간만 '⚠ 보간한 시각'으로 밝힌다.
