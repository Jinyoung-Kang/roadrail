# ADR-015 기차 경로를 실제 선로로 그리기 (OpenStreetMap)

- 상태: 채택 (2026-09-25)
- 배경: 판단 화면의 기차 경로가 역과 역을 잇는 직선이었다. 코레일 API 는 역별 시각만 주고 선로 좌표는 주지 않는다.

## 가능 여부 검토

| 후보 | 판단 | 근거 |
|---|---|---|
| 코레일 · TAGO API | 불가 | 선로 형상 없음 (역 코드 · 시각만) |
| 국가철도공단 노선 SHP · 국가공간정보 | 보류 | 파일 수동 내려받기 · 좌표계 변환 · 갱신 주기 불명 |
| **OpenStreetMap (Overpass API)** | **채택** | `railway=rail` 전국 약 2.4만 way, 키 없이 조회, ODbL (출처 표시 의무) |

## 결정

1. **수집 `rail_geometry` (매월 1일 · 첫 기동 시 비어 있으면)** — 전국을 4구역으로 나눠 `way["railway"="rail"](구역);out skel geom qt;`. 구역마다 공개 미러 3곳을 돌아가며 최대 6회(한 번에 전국을 받으면 504). User-Agent 필수(없으면 406). `service` 태그로 거르지 않는다 — 분기선·연결선이 빠져 그래프가 끊긴다(서울→용산이 86km 로 돌아감).
2. **그래프 `RailGraph`** — way 의 연속 점을 간선(하버사인 거리)으로. 역은 가상 노드로 두고 **반경 400m 안의 모든 선로 점**에 연결(없으면 1.2km 안 가장 가까운 점). 한 점에만 붙이면 반대 방향 본선에 붙어 크게 돌아간다.
3. **역 쌍** — 최근 14일 운행정보에서 **연속으로 정차한 역 쌍**만(약 1,000쌍). 출발역마다 다익스트라 한 번으로 모든 도착역을 구하고, 다른 역의 가상 노드는 지나가지 않는다(역을 지름길로 쓰지 않도록). 직선 대비 3.6배를 넘는 경로는 잘못 붙은 것으로 보고 버린다.
4. **저장** — Douglas–Peucker(30m)로 줄여 `ref.rail_link(dep, arr, path jsonb, length_km, straight_km)` 에 upsert (V8).
5. **API** — `RailJourneyService` 가 `ref.rail_link` 를 메모리에 두고(10분마다 다시 읽음) 여정 구간마다 **그 열차가 실제로 선 역 순서대로** 역 쌍 경로를 이어 `legs[].path` 로 준다. 경로가 없는 역 쌍은 두 역을 직선으로 잇고 `pathOnTrack=false`.
6. **화면** — 선로 경로는 주황 실선, 직선 대체 구간은 점선. 지도에 "선로 © OpenStreetMap contributors (ODbL)" 표시.

## 결과 (실측)

- 개발 중 검증: 24,172 way → 역 쌍 1,056/1,056 경로, 직선 대비 길이 중앙값 1.12 · p90 1.33 · 최대 3.44.
- 운영 첫 실행: VERIFICATION.md 21번 참고.

## 한계

- OSM 에 없는 신설 노선, 역에서 400m(최대 1.2km) 안에 선로가 없는 역은 직선으로 대체된다.
- 같은 역 쌍을 다른 선로로 달리는 열차(예: 고속선 · 기존선)는 최단 선로 하나로 그린다.
