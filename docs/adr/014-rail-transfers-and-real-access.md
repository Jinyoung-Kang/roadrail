# ADR-014 기차 환승 경로 (CSA) · 역까지 실제 경로 · 전국 도로 분석

- 상태: 채택 (2026-09-25)
- 배경: 직통 열차만 보면 전주→부산처럼 직통이 없는 조합은 비교 자체를 못 한다. 역까지 시간을 직선거리로 추정하면 도심·외곽 차이를 못 담는다. 도로 분석은 수집 중인 8개 길에 묶여 있었다.

## 가능 여부 검토 (실측)

| 요구 | 판단 | 근거 |
|---|---|---|
| 코레일 열차 간 환승 | **가능** | 전국 여객열차의 역별 시각을 3개월치 보관 중(ADR-003) → 하루 시간표로 경로 탐색 가능 |
| 역까지 · 역에서 실제 경로 | **가능 (차량)** | 카카오 다중 목적지 · 다중 출발지 길찾기 — 반경 10km 안 최대 30곳을 호출 1건으로 (강남→서울역 21.8분) |
| 역까지 도보 실제 경로 | 불가 | 공개 도보 길찾기 API 없음 → 1km 미만만 도보 추정(직선 × 1.3 ÷ 4.5km/h) |
| 지하철 · 버스 포함 대중교통 환승 경로 | **불가** | TAGO 지하철정보는 역별 출발 시각 · 종착역만 제공(열차 번호 · 역 순서 · 좌표 없음) → 역 사이 연결을 만들 수 없음. 카카오는 대중교통 길찾기 공개 API 없음. ODsay 등 별도 대중교통 API 키가 필요 |
| 지하철 정보 활용 | 가능 (안내) | 기차 출발역 · 도착역에서 갈아탈 수 있는 노선 · 방향 · 다음 열차 시각 (TAGO 역별 시간표) |
| 도로 분석 전국 임의 지점 | 가능 | 카카오 미래 운행 정보: 도로별 구간 · 소통 · 고속도로 회피(`avoid=motorway`) · 출발 시각별 |

## 결정

1. **CSA (Connection Scan Algorithm)** — `RailRouter` 순수 함수. 하루 시간표(`rail.day_stops`, V7: 중간역 계획 시각은 P-i1 보간)를 연결 약 1만 개로 펼쳐 출발 시각 순으로 한 번 훑는다. 같은 열차는 벌점 없이, 다른 열차로 갈아탈 때는 최소 10분. 목표일 + 다음 날 시간표를 이어 붙여 심야 출발도 다음 날 첫차로 잇는다. 여정 3개(출발 시각이 다른)를 돌려준다.
2. **역 후보** — 어디서 · 어디로 반경 30km 안의 운행 역 최대 6곳씩. 이동 시간: 1km 미만 도보 추정 · 9.5km 이내 카카오 다중 길찾기(실제 운전 경로) · 그 밖은 직선거리 추정(화면에 '추정'). 승차 여유 5분.
3. **판단 기준** — 자동차는 도로 기준(카카오 출발 시각 경로, 어디서 → 어디로 그대로), 기차는 '역까지 + 대기 + 탑승·환승 + 마지막 열차 평균 지연 + 역에서'.
4. **도로 분석 `/road/route`** — 추천 경로 · 고속도로 회피 경로(국도 · 일반도로 위주) · 출발 시각 8개(지금 ~ 12시간 뒤)를 병렬로. 도로 종류는 이름으로 분류(`RoadClass`) — 카카오 응답에 도로 등급이 없어 국도 구간이 도로명(예: 경수대로)이면 일반도로로 집계되는 한계를 화면에 적는다.
5. **예산** — 카카오 길찾기(`KAKAO`) · TAGO(`TAGO`)도 collector 와 같은 Redis 예산(`QuotaGuard`). 결과는 20분(경로) · 1일(시간표) · 7일(역 목록) 캐시.

## 결과 (실측)
- 전주시 → 부산역: 전주역(차량 11분, 5.6km) 06:28 → **오송 환승** → 09:39 부산역, 다른 여정 2개(익산 → 천안아산 환승). 부산역 1호선 다음 열차 표시. 캐시 미적중 0.63초.
- 강남역 → 전주시 도로 분석: 추천 2시간 24분(고속도로 98%) · 회피 4시간 4분 · 03:55 출발이 가장 빠름(2시간 18분). 새 조합 첫 계산 2.3초(카카오 9건 병렬).
