# ADR-030 화면 글 — 문장마다 한 줄 · 어절 단위 줄바꿈 · 쉬운 한글 용어

- 상태: 채택 (2026-10-10)
- 배경: 사용자 요청(2026-10-10). 설명 문단이 구절 중간 · 낱말 중간에서 줄이 바뀌었다(예: "서비\n스입니다", 모바일에서 더 심함).
  예측 성능 화면의 채점(백테스트) 영역은 MAE · MAPE · horizon · M0/M1 · n 같은 영어 · 기호를 그대로 썼다.

## 결정

1. **전역: 어절 단위 줄바꿈.** `body { word-break: keep-all; overflow-wrap: break-word }` — 한글 낱말 안에서 끊지 않고, 넘치는 긴 낱말(주소 · 영문
   식별자)만 칸 안에서 끊는다. 문단은 `text-wrap: pretty`(끝 줄에 한두 낱말만 남지 않게), 제목은 `balance`.
2. **설명은 문장마다 한 줄.** `components/ui` 의 `Lines` — 글 조각을 순서대로 이어 붙이고 문자열 안의 문장 끝(한글 · 닫는 괄호 · 따옴표 · % 뒤의
   마침표)에서만 새 줄을 연다(`lib/text` `toLines`, 단위 시험). 숫자 뒤 마침표는 문장 끝이 아니다(날짜 "10. 10." · 소수). 끼워 넣은 값 앞뒤에서는
   끊지 않는다. `Section` 설명 · `PageHero` 부제 · `Note` 는 자동으로, 그 밖의 설명 문단은 `<Lines>` 로 감싼다. 서버가 주는 안내 문구도 같은 규칙.
   - 고르지 않은 것: 문장마다 `<br>` 을 문자열에 넣기(서버 문구 · 끼워 넣은 값에 적용할 수 없음), 폭에 따라 줄을 바꾸는 계산(글꼴 · 폭마다 다름).
3. **이름 목록은 이름 단위로.** 출처 목록처럼 " · " 로 이은 이름은 `Joined` — 이름 하나는 한 덩어리(`inline-block`)라 이름 중간에서 줄이 바뀌지 않는다.
4. **예측 성능 용어.** 백테스트 → 지난 기록으로 채점, horizon → 몇 분 뒤, MAE → 평균 오차, MAPE → 평균 오차율, n → 채점 횟수,
   M0 기준선 → 평소 값, M1 기준선+편차 → 평소 값 + 지금 차이, 지속 → 지금 값 그대로, 선행(lead) → 마지막 관측에서 N분 뒤,
   F-v1(tau=90) → 규칙 F-v1 · 지금 차이가 줄어드는 속도 90분. 판단 화면 자동차 카드의 예측 방법 이름도 같은 말(`MODEL_LABEL`).
   API 의 열쇠 이름(`M0` · `M1` · `persistence` · `maeSec`)과 ADR · 코드의 규칙 이름은 그대로 둔다.

## 결과

- 웹 단위 49(+5: 문장 나누기 · 줄 묶기 · 예측 방법 이름 · 규칙 문구), E2E 예측 성능 1(영어 용어 없음 · 문장마다 한 줄 · keep-all).
- 화면 순회(8화면 × 데스크톱 · 모바일) 가로 넘침 0. 순회 스크립트가 누른 버튼 때문에 화면이 바뀌면 사라진 버튼을 끝없이 기다리던 것을 고쳤다.
