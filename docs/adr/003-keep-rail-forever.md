# ADR-003 운행정보는 매일 수집 · 영구 보관

- 상태: 채택
- 결정: 코레일 운행계획·운행정보를 전국 전 열차 단위로 매일(03:30) 받아 무기한 보관한다. `rail.run_info` 는 월 파티션.
- 이유: API 조회 가능 기간이 약 3개월 ~ 어제다 (실측 2026-06-20 ~ 09-23). 지나면 다시 받을 수 없다. 하루 3회 호출로 전국을 받으므로 코리도 역 쌍을 나중에 바꿔도 과거를 다시 계산할 수 있다 (`roadrail recompute-rail`).
- 첫 기동: 조회 가능한 92일을 자동 백필 (276건 호출, 약 3분, 83만 행).
