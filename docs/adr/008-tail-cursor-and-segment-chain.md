# ADR-008 도로: 구간 체인 합산 + 꼬리 커서 수집

- 상태: 채택
- 배경 (W1 실측): 장거리 영업소 쌍은 표본이 5분당 1~6대라 휴게소 정차가 평균을 부풀린다. 응답은 오늘 하루 전체를 99행씩 주고, 공개 지연이 약 3시간이다.
- 결정:
  1. 코리도 = 방향별 인접 영업소 구간 체인. 체인은 `tools/build_seed.py` 가 행 수로 표본을 확인하며 자동 선택.
  2. 구간마다 '오늘 본 1종 행 수'를 Redis 에 두고 그 행이 있는 **꼬리 페이지만** 10분마다 받는다 (보통 구간당 1회). 5분 폴링은 공개 지연 때문에 이득이 없다.
  3. 받은 슬롯 범위만 코리도 합산을 다시 계산한다. 늦게 공개·수정된 값도 자연키 UPSERT 로 반영.
- 결과: 구간 106개 → 하루 약 15,000건. 서울→천안 상행 합 52~55분 ↔ 카카오 55분.
