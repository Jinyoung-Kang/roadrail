# ADR-002 공급자별 예산을 Redis 원자 연산으로 예약

- 상태: 채택
- 결정: 작업 시작 시 예상 호출 수를 Lua 스크립트(읽기-비교-증가 1회)로 예약하고, 호출마다 차감·부족분은 1건씩 추가 예약, 끝나면 환불한다. 확정값은 `ops.quota_budget` 에 저장.
- 이유: 에어코리아 개발계정 500건/일처럼 한도가 설계를 결정한다. 동시 작업(스케줄 + 관리 API 수동 실행)이 경쟁해도 한도를 넘지 않아야 한다.
- 검증: `test_concurrent_reservations_never_exceed_limit` — 동시 20개 × 30건, 한도 500 → 정확히 16개만 성공.
- 대안: DB 행 잠금 — 가능하지만 호출마다 트랜잭션이 필요하고 느림.
