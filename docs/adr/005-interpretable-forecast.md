# ADR-005 예측은 해석 가능한 기준선 모델부터

- 상태: 채택
- 결정: M0(요일·슬롯 기준선), M1(기준선 + 현재 편차 × e^(−h/τ)), 지속 모델 세 가지를 같은 백테스트로 비교한다. 발행일마다 이전 8주로만 기준선을 다시 만들어 누수를 막는다.
- 이유: 데이터가 쌓이기 전에는 ML 모델을 검증할 수 없다. 기준선 모델은 설명 가능하고, '지속보다 나은가'라는 최소 기준을 숫자로 보여 준다.
- 언어 간 계약: 같은 식을 collector(Python, 백테스트)와 api(Java, 판단 카드)가 각각 구현하므로 `fixtures/forecast_cases.json` 골든 케이스를 양쪽 테스트가 공유한다. 반올림도 half-up 으로 통일 (Python `round` 는 은행가 반올림).
