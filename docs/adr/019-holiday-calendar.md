# ADR-019 공휴일 달력 (한국천문연구원 특일 정보)

- 상태: 채택 (2026-09-25)
- 배경: 수집 기간에 제헌절 · 광복절 · 대체공휴일 · 추석이 있었고, 수집 시작일(09-24)이 추석 연휴다.
  - 도로: 추석 서울→대전 하행 6시간 24분(평소 약 1시간 50분)이 '평소' 요일 기준선에 들어갔다.
  - 철도: 추석 09-24(목) 코레일 운행 931편 ↔ 같은 목요일 09-17 875편(임시열차). 다음 주 목요일 기차 시간표로 추석을 쓰게 되어 있었다.

## 결정

- `holiday_sync` 작업: `getRestDeInfo(solYear)` 로 작년 · 올해 · 내년(3회) → `ref.holiday` (V15), 매월 1일 · 첫 기동.
- 도로 기준선 · 백테스트 기준선 입력에서 공휴일 제외 (`compute_baseline(df, holidays)`).
- 기차 기준 시간표: 평일 목표일이면 공휴일이 아닌 같은 요일 최근 운행일, 목표일이 공휴일이면 같은 요일 최근 운행일을 쓰고 '공휴일 임시열차는 반영되지 않음'을 표시.
- 요일별 정시율: 공휴일은 요일 대신 'H'(공휴일).
- 판단 경고: 출발일이 공휴일이면 이름과 함께.
- 지하철 시각: TAGO 요일 구분 코드는 01 평일 · 02 토요일 · 03 일요일뿐(활용가이드 v1.1)이라 공휴일에 어느 시간표가 적용되는지 API 로 알 수 없다 → 공휴일엔 표시하지 않는다(추정하지 않음).

## 결과

- 2025~2027 공휴일 66일. 기준선 로그 '공휴일 4일 제외' — 지금까지의 도로 자료가 모두 공휴일이라 기준선이 비었고(09-27 부터 채워짐) 화면에 이유를 적었다.

## 쓰지 않은 API

- 서울특별시 버스 노선정보: 노선 · 정류소 · 첫차/막차만 있고 정류소별 도착 시각이 없으며, 정류소 → 노선 조회가 없어 기차역의 버스를 찾으려면 서울 전 노선을 긁어야 한다. 서울 한정이라 도시 간 판단에 반영할 수 없다.
