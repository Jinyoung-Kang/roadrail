# ADR-006 판단은 규칙 기반 + 근거 목록

- 상태: 채택
- 결정: R-DEC-01 (자동차 = 도로 예측 + IC 접근, 기차 = 역 접근 + 대기 + 계획 소요 + 30일 평균 지연, 10분 미만은 '비슷함')을 순수 함수(`DecisionRule`)로 두고, 결론과 함께 사용한 수치·데이터 시각을 근거 목록으로 반환한다.
- 이유: 근거 없는 추천 방지 (NFR-06). 한쪽 데이터가 없으면 결론 대신 '비교할 수 없습니다'.
- 현실 보정: 기차는 '출발 + 역 접근 시간' 이후 첫 열차로 계산한다 (역에 도착하기 전에 떠난 열차는 탈 수 없다). 조기 도착(음수 지연) 평균은 0 으로 본다.
