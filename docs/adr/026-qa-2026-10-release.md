# ADR-026 출시 기준 QA — DB 소켓 읽기 제한 · 겹치는 백필 거절 · 프록시 오류 규약 · 라디오 그룹 키보드 · 정보 글자 대비

- 상태: 채택 (2026-10-04)
- 배경: 실무 출시 기준 QA([계획](../qa/2026-10-04-qa-plan.md) · [보고서](../qa/2026-10-04-qa-report.md))에서 결함 9건(Medium 7 · Low 2)을
  실패하는 시험으로 재현했다. 고치면서 동작이 바뀌거나 앞으로도 지켜야 할 결정만 여기에 남긴다.
- 원칙: 새 의존성 · 새 마이그레이션 없이 원인이 있는 곳만 고친다. 장애 주입 · 부하 · 비정상 입력은 외부 API 키가 없는 분리된
  QA 스택(`qa/compose.qa.yml`)에서만 한다.

## 결정

1. **API 의 DB 연결에 소켓 읽기 제한 15초(QA-02).** Hikari `data-source-properties: socketTimeout=15, tcpKeepAlive=true`.
   - pgjdbc 는 기본으로 읽기 제한이 없어 DB 가 멈추면(일시 정지 · 네트워크 단절) 요청과 연결이 끝없이 묶였다.
   - `statement_timeout`(서버 쪽)은 서버가 멈춘 경우를 막지 못해 고르지 않았다. 15초는 가장 무거운 조회(366일 정시율 0.34초)의 40배 이상.
   - 수집기 쪽 같은 상황은 이번에 확인하지 못했다(보고서 6절 미확인).
2. **겹치는 기간의 백필은 409(QA-05).** 대기(QUEUED) · 실행(RUNNING) 중인 백필과 기간이 겹치면 `JOB_RUNNING`.
   확인과 등록은 한 트랜잭션에서 자문 잠금(`pg_advisory_xact_lock`) 뒤 `INSERT … WHERE NOT EXISTS` — 동시에 들어와도 하나만 들어간다.
   - 배제 제약(`EXCLUDE USING gist`)은 `btree_gist` 확장과 마이그레이션이 필요하고, 이미 끝난(DONE · FAILED) 행은 겹쳐도 되므로 부분 제약이 된다 —
     관리 명령은 드물어 잠금으로 충분하다. 예산 부족(429) 판단은 그 앞에서 그대로.
3. **웹 프록시는 오류도 오류 규약으로(QA-06).** 주소가 4KB 를 넘으면 API 에 보내지 않고 414 `VALIDATION_ERROR`.
   API 앞단(Tomcat)이 거른 요청의 HTML 오류처럼 JSON 이 아닌 4xx · 5xx 는 `{code, message, traceId}` 로 바꾼다.
   API 를 직접(127.0.0.1:8300) 부르는 경우의 Tomcat HTML 400 은 그대로 둔다(외부에 열리지 않은 주소).
4. **라디오 그룹은 ARIA 방식(QA-08).** `Segmented` 는 고른 항목 하나만 탭 정지(roving tabindex), 화살표 · Home · End 로 옮기며 바로 고른다.
5. **정보를 담은 글자는 muted 이상(QA-03).** `faint`(흰 바탕 3.3:1)는 장식 · 비활성에만. 차트 범례 글자는 글자 색, 계열 색은 선 표식에만.
6. **빈 값이 채워져도 화면이 밀리지 않게(QA-04 · 09).** 본문 최소 한 화면 높이(꼬리말), 빈 제목도 줄 높이 유지, 모바일에서 값이 들어오며
   줄 수가 바뀌는 부제 · 판단 문구는 처음부터 그 줄 수로, 값을 읽은 뒤에야 생기는 버튼은 보이지 않는 같은 크기 자리로 먼저 둔다.
7. **QA 시험은 CI 에 넣지 않는다.** `web/e2e/qa-*.spec.ts` 는 데이터가 있는 스택이 떠 있어야 해 수동으로(`E2E_BASE_URL` 로 QA · 개발 스택 선택),
   API 쪽 QA 시험(`ApiIT.qa01_*` · `qa05_*` · `DbStallIT`)은 Testcontainers 라 CI 에서 돈다.

## 결과

- 재현 시험: API 4건(`ApiIT` 3 · `DbStallIT` 1) · E2E 14건 — 수정 전 실패, 수정 뒤 통과(별도 리뷰어가 수정 전후 커밋에서 다시 확인). 회귀: collector 125 · API 131 · 웹 단위 35 · E2E 29.
- DB 정지: 헬스 40초 넘게 무응답 → 15초에 503 DOWN, 재개 즉시 200. 동시 백필 5건: 202 ×5 → 202 1 · 409 4.
- Lighthouse 접근성 `/road` · `/road/SEL-DJN` 96 → 100, CLS `/road` 0.279 → 0.003(데스크톱) · `/rail` 모바일 0.154 → 0.011 · 홈 모바일(비교할 수 없음) 0.139 → 0.026.
