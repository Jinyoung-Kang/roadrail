# ADR-010 카카오 미래 운행 정보는 비동기 + 최대 0.6초 대기

- 상태: 채택
- 배경: 판단 카드 캐시 미적중 p95 < 1초 (NFR-03) 인데 카카오 응답이 약 1초 → 미적중 1.57초 측정.
- 결정: 카카오 호출을 가상 스레드에서 실행하고 판단 카드는 최대 0.6초만 기다린다. 늦으면 카카오 값 없이 응답하고 호출은 끝까지 진행해 20분 캐시를 채운다. 같은 키의 동시 호출은 하나로 합친다.
- 결과: 미적중 0.52~0.82초, 적중 7~9ms. 카카오는 교차 확인용이고 판단은 자체 예측으로 하므로 첫 응답에서 빠져도 결론은 바뀌지 않는다.
