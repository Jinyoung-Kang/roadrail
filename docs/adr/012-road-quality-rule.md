# ADR-012 도로 품질 규칙 Q-v2 · 튀는 값 제거 H-v1

- 상태: 채택 (Q-v1 대체)
- 배경: Q-v1(암시 속도 < 40km/h ∧ 차량 < 5 → SUSPECT)은 휴게소 정차 혼입을 거르려 했지만, 2026-09-24 추석 귀성길의 **실제 정체** 1,132행을 잘못 걸렀다. 정체 때는 가장 빠른 차량(timeMin)도 느리다.
- 결정:
  - 수집 시점 Q-v2: 평균 속도 < 8 ∨ > 170km/h, 또는 (차량 ≥ 2 ∧ 최소시간 속도 ≥ 60km/h ∧ 평균 ≥ 2.5 × 최소) — 흐르는 차와 멈춘 차가 섞인 경우만.
  - 합산 시점 H-v1: 같은 구간 ±30분 중앙값의 2배를 넘고 차량 < 5 인 고립된 값 제외 (정체는 점진적, 정차 혼입은 한 슬롯).
  - 규칙을 바꾸면 `roadrail reclassify-road` 로 저장된 행을 API 호출 없이 재분류·재합산.
- 결과: SUSPECT 1,132 → 44행. 테스트: 정차 혼입 · 실제 정체 · 점진적 증가 · 표본 많은 급증을 각각 고정.
